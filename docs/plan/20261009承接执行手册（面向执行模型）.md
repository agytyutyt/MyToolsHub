## 1. 全局规则（每卡通用）

### 1.1 环境
- 仓库 `D:\JZToolsHub`；Git Bash；分支 `desktop`；python 用 PATH 上的 `python`（3.14）。
- `deploy/`、`build/`、`dist/`、`runtime/` 在 `.gitignore`（产物不入库）；入库的只有源码/文档/登记文件（如 `tools/plugin-packages.json`）。
- 控制台出现 `LF will be replaced by CRLF` 是正常警告，忽略即可。

### 1.2 提交与出包纪律
1. 动手前 `git status --short`：有**非本卡**的未提交改动 → 停下报告（别合并提交）。
2. 提交只用显式路径：`git add <文件1> <文件2>`；**禁止** `git add -A` / `git add .`；**不 push**。
3. 提交信息中文、格式 `类型(范围): 摘要`（如 `fix(info-transfer): …`；`chore(registry): …`；`docs: …`）。
4. 出包类：**先 commit（脚本/源码）→ 再构建（产物）→ 再 commit 登记文件**。遇 `index.lock` 冲突重试一次。

### 1.3 验收与红灯
- 每卡「验收」的命令必须实跑并把**关键输出**贴进 §B 记录；全绿才可给卡打 ✅。
- 红灯（命令报错/期望不符/门禁拦截）= **停本卡**：写失败报告（§A3）→ 继续下一卡（除非下一卡依赖它）。

### 1.4 禁止事项（全局）
- 不改卡内未列出的文件；不改 `docs/archive/`（冻结留证）。
- `HANDOFF.md` §3 等**带日期的历史记录条目**不改（只改“现状”性描述，如 §10 结构表）。
- 不在工具会话里跑整包 `build-deploy.ps1`（已知 `Remove-ObjectNotBound` 类问题，见打包部署手册故障表）。
- 不删既有文件，除非卡片明确列出该文件。

  `python - <<'EOF'`
  `import zipfile,json,glob`
  `for f in glob.glob('deploy/插件包/本地插件/PATTERN*.zip'):`
  `    z=zipfile.ZipFile(f); m=json.loads(z.read([n for n in z.namelist() if n.endswith('manifest.json')][0]))`
  `    print(f.split('/')[-1],'| version=',m.get('version'),'| timeout_ms=',m.get('timeout_ms'),'| idle_ttl=',m.get('idle_ttl'),'| README=',('README.md' in z.namelist()))`
  `EOF`
- **V2 三方 sha 核对**（服务器包）：
  `python - <<'EOF'`
  `import json,hashlib,glob,os`
  `reg=json.load(open('tools/plugin-packages.json',encoding='utf-8'))['packages']`
  `for f in glob.glob('deploy/插件包/服务器插件/JZToolsHub-info-transfer-*-v1.2.11.zip')+glob.glob('deploy/插件包/服务器插件/JZToolsHub-qr-video-decode-*-v1.2.0.zip'):`
  `    sha=hashlib.sha256(open(f,'rb').read()).hexdigest(); side=open(f+'.sha256',encoding='utf-8').read().split()[0]`
  `    pid='info-transfer' if 'info-transfer' in f else 'qr-video-decode'; ver='1.2.11' if pid=='info-transfer' else '1.2.0'`
  `    r=[v for v in (reg[pid].get('versions') or []) if v.get('version')==ver][0]`
  `    key='sha256' if '-后端-' in f else 'frontend_sha256'`
  `    print(os.path.basename(f),'OK' if sha==side==r.get(key) else 'MISMATCH')`
  `EOF`
- **V3 读 catalog**：`python - <<'EOF'`
  `import json,os; c=json.load(open(os.path.expanduser('~/.jztoolshub/store/catalog.json'),encoding='utf-8'))`
  `for e in c['packages']:`
  `    v=[x for x in e.get('versions') or [] if x.get('status')=='published']`
  `    if v: print(e['id'], v[-1]['version'], repr(e.get('name')), v[-1].get('status'))`
  `EOF`
