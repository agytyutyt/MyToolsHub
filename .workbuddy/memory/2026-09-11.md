### 关键结论与踩坑（已写入 HANDOFF §7）
1. **Flask 视图函数名全局唯一**：插件路由函数必须带插件前缀（`ts_status` 等），
   否则与 file-filter 的 `def status()` 冲突导致插件整体加载失败。
2. **Werkzeug 3 的 test_client 忽略手写 Cookie 头**：插件间"进程内派发"必须用
   `client.set_cookie(name, value, domain="localhost")`，否则内部请求变匿名 → 401。
3. **跨项目算法对拍必须对齐计量口径**：地球半径 6378137 + round 取整；地点簇建在
   "清洗后未去重"的行上；质量报告采样间隔含 0 间隔而 T_thr 用有效间隔。
4. 上游 `output/v2/` 是 git 提交版样本的产物，仓库里 `demoData_real.xlsx` 已被换过
   （号码 15728345997 → 15700000007），对拍须 `git show <commit>:demoData_real.xlsx`。
