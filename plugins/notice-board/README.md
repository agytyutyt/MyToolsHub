# 公告板（notice-board）

单位与部门公告发布与查看插件。

## 功能

- **查看**：全体登录用户默认可用（`config/tools.json` 中 `grant_all: true`，无需逐人授权）；
- **发布**：仅「管理员」角色（role-admin）与超级管理员。发布对话框为左右结构：
  左侧输入标题与内容，右侧选择可见范围——
  单位→部门→用户 树状勾选（左）｜「选择」按钮（中）｜已选对象框（右，可逐项移除）；
- **可见性**：公告仅对所选对象可见，命中任一目标即可见；
- **删除**：发布者本人或超级管理员。

## 可见性规则

| 目标类型 | 可见条件 |
| --- | --- |
| 单位 | 与目标同单位的用户 |
| 部门 | 与目标同部门且同单位的用户 |
| 用户 | 该用户本人 |
| 超级管理员 | 全部可见 |

## 依赖

无第三方依赖（纯标准库）。组织树数据来自 admin 插件只读接口 `GET /api/admin/org-tree`。

## 已知限制

- 发布角色依据 admin 插件的角色 ID（role-admin）/角色名（管理员）判定，
  如在「权限管理」中重建同名角色请保持 ID 一致；
- 公告暂不支持编辑，可删除后重新发布。
