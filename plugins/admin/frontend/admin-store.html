商店管理

上架 → 审核（装机冒烟必做）→ 发布；server 条目发布时自动部署后端包。
流程与口径速览（点开查看）
  • 上架 = 包上传 + 机器校验 → 待审核；审核通过即发布，对客户端可见。
  • server 条目发布时自动部署后端包（含备份，可回滚）；桌面端「安装」= 仅装前端包。
  • C 类配对（2026-10-11）：server 条目可附「客户端工件包」（local-<id>，同版本号）—— 一次审核发布两条目（商店只出客户端工件卡，后端包发布即部署、不出卡）。
  • 下架最新版 = 客户端可见性自动回落旧版（已装新版客户端不降级）；配对条目同进同出。
  • 同 id 同版本号（含已驳回/已下架记录）拒绝重提——版本占号，问题包须升版重来。
  • 审核纪律：装机冒烟为必做项（白名单外取数等运行期问题在此暴露）；四眼为软约定。
  • 权限（2026-10-08 修订）：提交上架全员可用；审核 / 驳回 / 下架 / 重新部署仅管理员与超级管理员（内网信任模型 + 会话鉴权 + 机器校验兜底）。

拖拽包文件到此处，或点击选择（.zip）
命名识别：JZClient-本地插件-*.zip → local ｜ JZToolsHub-插件-*.zip → server（需配对前端包）｜ JZToolsHub-依赖-*.zip → dep-slot

按包形态上传：local=本地插件包 · server=后端包 + 前端包成对（同版本号）· dep-slot=依赖组件包。依赖从包内 manifest 读取，上架时逐项核验展示（✓ 满足 / ✗ 不满足）： 不满足可提交审核，但须待对应依赖组件包上架（可由插件制作者或其他用户上传）后才能发布。
