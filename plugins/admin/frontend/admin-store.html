商店管理

插件商店的写面：上架 / 审核 / 发布 / 下架 / 统计（全流程不设角色门槛，机器校验 + 审核纪律兜底）。 上架 = 包上传 + 机器校验 → 待审核 → 审核通过即发布（server 条目发布时自动部署后端包）； 下架最新版 = 客户端可见性自动回落旧版；同版本号含已驳回即拒绝重提（版本占号）。 装机冒烟为审核必做项（白名单外取数等运行期问题在此暴露）。
