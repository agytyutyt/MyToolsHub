插件管理

用「插件包」单独升级某一个插件（不必重出整包）：管理员在这里上传 .zip， 程序自动完成校验 → 备份 → 替换 → 停服重启，全程无需人工解压或敲命令；出问题可一键回滚。 插件的用户数据全程不受影响。

插件盘点

「代码版本」= 程序目录里插件目录的当前版本；「登记版本」= 上次通过插件包安装时登记的版本。 两者不一致通常说明目录被人工改动过。

离线升级包（单个插件）

选择由 tools\build-plugin-package.ps1 生成的 JZToolsHub-插件-<插件id>-v<版本>.zip（不要解压，整包上传即可）。 上传后先做只读校验并给出计划，确认应用后：自动备份旧版 → 替换代码 → 若含后端改动则自动停服重启，本页随后自动刷新。

共享盘批量更新

指向内网共享盘上由出包工具维护的 index.json（与包文件同一目录）。 检查更新只读索引与包文件；批量升级会按顺序应用勾选的包，全部成功后若含后端改动则自动统一重启一次。
