数据迁移

把当前已安装插件的数据按插件分类打包导出，或从迁移包导入；导出包整包口令加密
← 后台首页

导出数据

勾选要带走的数据段，设置一个导出口令后下载 .jzdata 包。 包内按插件分类存放（plugins/<插件>/…），整包用口令加密： 没有口令连包内文件名都读不到，账号数据里的密码、身份证与大模型 API Key 也不会以可读形式出现。

导入数据

选择 .jzdata 包并输入当时的导出口令 → 先解析预览（此时不写任何数据）→ 确认要导入的数据段后再执行。覆盖前会把被替换的文件备份到数据根 backups/migrate/<时间戳>/，导错可手工回退。

导入「账号与权限数据」会替换现有账号——若当前登录账号不在包内，导入后需要重新登录。
