查找内容替换为（留空=删除）正则启用

大模型（大模型过滤模式使用）

接入信息（格式 / 地址 / Key / 模型）统一在 「管理后台 → 大模型设置」维护；若管理员开启了「用户各自设置」， 也可在首页右下角「⋯ → 大模型设置」中自行填写。本插件不再单独保存 API Key。
