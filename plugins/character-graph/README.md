# 人物关系立体星图（character-graph）

全栈插件，上传文档（小说/剧本/笔录）→ 大模型抽取人物关系 → Three.js 3D 星图可视化。

## 功能

- **文档上传**：支持 .txt / .md / .json / .csv / .docx / .pdf，后端自动提取纯文本；
- **大模型关系抽取**：经主体模块 `jz_llm` 调用大模型（调用格式 / 地址 / Key / 模型由统一大模型配置解析），提取人物节点与关系边；
- **3D 可视化**：Three.js 渲染可旋转/缩放/平移的立体星图，节点悬浮显示详情；
- **异步任务**：文件接收后立即返回 task_id，后端线程池异步执行，前端轮询进度；
- **配置持久化**：本插件**不持有任何大模型接入信息与凭据**——接入信息由统一大模型模块 `jz_llm`
  管理（见「注意事项」），本插件只拟定并保存提示词（数据根 `prompt.json`，经 `GET /prompt` 读取）。

## 接口（前缀 `/api/character-graph`）

| 接口 | 方法 | 说明 | 权限 |
| --- | --- | --- | --- |
| `/config` | GET | 读大模型可用状态：`llm_configured` / `llm_source` / `llm_source_label` / `llm_reason`（不回传地址与 Key） | 登录 |
| `/config` | POST | 兼容占位：本插件已无可写配置项，仅回 `ok` + `llm_configured` | 登录 |
| `/prompt` | GET | 读取提示词 `{system, user_template}`（数据根 `prompt.json`，首次启动自动生成默认值） | 登录 |
| `/status` | GET | 依赖自检（`python-docx` / `pypdf` / `requests`，缺依赖时优雅降级） | 登录 |
| `/analyze` | POST | multipart `file` → 异步返回 `{ok, task_id}`；缺文件 / 空文件 / 大模型未配置 → 400 | 登录 |
| `/result/<task_id>` | GET | 轮询任务：`status`（pending / running / done / error）+ `filename`；`done` 另有 `graph`，`error` 另有 `detail`；任务不存在或已过期 → 404 | 创建者/超管 |

## 依赖与升级

| 项 | 内容 |
| --- | --- |
| 框架已打包依赖 | `flask` >=3.0（必需，随主包） |
| 依赖组件包（不随主包） | `docx` >=1.0、`pypdf` >=4.0、`requests` >=2.31（缺失时对应功能降级：Word/PDF 解析、大模型关系抽取） |
| 插件自带依赖（`backend/vendor/`） | 无 |
| 外部程序组件 | 无 |
| 能否单独升级 | ✅ 可以——业务依赖走「依赖组件包」，插件不 import 其他插件（构建期 C-4/C-10/C-11 校验） |
| 升级是否需重启 | 含 `backend/**` 改动**需要**重启（后台/安装器会自动重启，约 5~10 秒）；纯前端改动免重启，Ctrl+F5 即可 |

> 声明真源是 `manifest.json` 的 `requires`（三类依赖：框架包 / 自带 vendor / 外部程序组件）；
> 出包工具构建期校验「声明 ↔ 实测 import」一致（C-10）。后台「插件管理」按它显示
> 逐依赖徽标与可运行性：缺**必需**依赖 → 标记不可运行并暂不加载，补齐后重启自动恢复；
> 缺**可选**依赖 → 照常加载但标注功能降级。规范依据：《插件设计规范》§15 U-7a / U-8。

## 注意事项

- 使用前请在「大模型设置」（「管理后台 → 大模型设置」/ 首页右下角「⋯ → 大模型设置」）配置大模型接入信息；本插件不保存 API 地址与 Key，运行配置位于数据根 `<数据根>/plugins/character-graph/config.json`（目前无自有可写配置项）。
- 文档文本过长（>120,000 字符，非字节）时自动截断，超出部分可能影响关系抽取完整度；
- PDF 扫描件无法提取文字，请确保上传的 PDF 为文本型（非纯图片扫描）；
- 分析结果保留 30 分钟，超时后需重新上传。
