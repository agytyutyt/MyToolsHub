信息传输

把文字 / 文档封装为二维码（静态图片或动态视频流）；精简传输只传数据不传格式，原件传输完整还原原文件

1. 输入信息

拖拽文件到此处，或点击选择（可多选）

仅支持 Word 文档(.docx) / Excel 表格(.xlsx / .xlsm / .xls) / CSV 表格(.csv) / 纯文本(.txt) / Markdown(.md)

精简传输只传数据不传格式（原件传输开启后文件原样封装）；.doc/.xls 等旧版格式自动按原件传输

原件传输
默认精简传输：只传数据不传格式，二维码更少。开启后文件原样封装（保留全部字节），生成的二维码数量将大大提高。
