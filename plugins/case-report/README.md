# 战果录入（case-report）

输入收网情况报告 → 大模型抽取**案件要素**（案件名 / 时间 / 主办大队 / 抓获人数 / 涉案价值；主办人不参与解析，保存时默认取录入人）+ 缴获物品明细 → 本地 JSON 台账（字段真源：`backend/parser.py` 的 `FIELD_KEYS`）。

## 功能

- **LLM 解析**（仅大模型，无本地规则/正则）：输入报告文本，后台任务异步调用 LLM 结构化输出 案件名 / 时间 / 主办大队 / 抓获人数 / 涉案价值 / 缴获物品 + 缴获物品明细（含类别 / 名称 / 数量 / 单位）；
- **手动录入**：跳过大模型解析，直接填写要素与明细入库；
- **主办大队**：下拉框限定为 一大队 / 二大队 / 三大队（`org_units.json` 配置）；
- **涉案价值**：仅由 LLM 提取，原文未提及则留空；
- **缴获物品明细**：提取结果以可编辑表格默认展开显示，支持修改类别 / 名称 / 数量 / 单位，修改类别后自动记忆（学习入库）；
- **同案合并**：检测到规整后案件名已存在时弹出合并确认；
- **战果汇总**：跨记录按类别累加，自动归并重量 / 货币单位，按「涉及 N 起」去重；
- **导出 Excel**：按当前筛选条件导出台账。

## 配置

| 项 | 位置 | 说明 |
| --- | --- | --- |
| **大模型接入信息**（格式 / 地址 / Key / 模型） | 「管理后台 → 大模型设置」，或首页右下角「⋯ → 大模型设置」（"用户各自设置"模式） | **不在插件里配置**：接入信息归主体模块 `jz_llm`，本插件不持有也不回传任何密钥（`GET /config` 只回"能不能用 + 用的是哪一份"） |
| **系统提示词与用户消息模板** | `<数据根>/plugins/case-report/prompt.json` | 首次启动自动生成（内容 = 插件内置默认值）；结构 `{"system": …, "user_template": …}`。**目前无界面入口，只能改文件**；每次解析都会现读该文件，改完下一次解析即生效（无需重启）；文件缺失/损坏时自动回退内置默认值 |
| **主办大队可选值** | `plugins/case-report/backend/org_units.json` | 插件目录内固化、随插件分发；改它需覆盖插件文件 |

> ⚠️ **不要再按旧版本创建 `backend/config.json` 或 `backend/prompt.json`**：
> 插件目录里没有这两个文件，代码也不再读取它们。其中 `config.json` 的内容**始终被忽略**
> （历史遗留文件会被首启迁移搬到数据根，但并不生效）；`prompt.json` 只有被迁移到数据根后
> 才生效，且仅限"目标尚不存在"的那一次启动——**照旧文档操作等同于配置未生效**。
>
> 数据根默认是 `<用户主目录>\.jztoolshub`（可用 `JZTOOLS_DATA_ROOT` 显式指定），
> 布局见仓库 `README.md` §4.2。

## 依赖与升级

| 项 | 内容 |
| --- | --- |
| 框架已打包依赖 | `flask` >=3.0（必需，随主包） |
| 依赖组件包（不随主包） | `openpyxl` >=3.1（**可选**：缺失时 Excel 导出不可用）、`requests` >=2.31（**可选**：缺失时大模型调用不可用） |
| 插件自带依赖（`backend/vendor/`） | 无 |
| 外部程序组件 | 无 |
| 能否单独升级 | ✅ 可以——业务依赖走「依赖组件包」，插件不 import 其他插件（构建期 C-4/C-10/C-11 校验） |
| 升级是否需重启 | 含 `backend/**` 改动**需要**重启（后台/安装器会自动重启，约 5~10 秒）；纯前端改动免重启，Ctrl+F5 即可 |

> 声明真源是 `manifest.json` 的 `requires`（三类依赖：框架包 / 自带 vendor / 外部程序组件）；
> 出包工具构建期校验「声明 ↔ 实测 import」一致（C-10）。后台「插件管理」按它显示
> 逐依赖徽标与可运行性：缺**必需**依赖 → 标记不可运行并暂不加载，补齐后重启自动恢复；
> 缺**可选**依赖 → 照常加载但标注功能降级。规范依据：《插件设计规范》§15 U-7a / U-8。

## 重要变更

- 移除所有本地规则 / 正则解析，字段全由 LLM 结构化输出；
- 移除 `/items` 接口，缴获物品明细改为 LLM 返回的结构化数组，前端可编辑；
- 主办大队改为下拉框选择（不再自由输入）；
- 涉案价值仅由 LLM 提取，原文未提及则留空；
- 提取结果卡片入库后自动隐藏。
