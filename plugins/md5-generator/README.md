# MD5 生成器（md5-generator）

纯前端 MD5 计算工具，所有计算在浏览器本地完成，文件不上传服务器。

## 功能

- **文本 / 文件 MD5**：实时计算，输入即出结果；
- **HMAC-MD5**：带密钥的身份验证码模式；
- **MD5 校验**：比对期望值，快速判定文件或文本完整性；
- **一键复制**：小写/大写两种格式，点击即可复制到剪贴板。

## 依赖

无第三方依赖。MD5 实现为 `frontend/md5.js` 原生 JS（RFC 1321 兼容），无外部库。

## 注意事项

- HMAC 密钥与待计算内容均仅在浏览器内存中处理，不会离开本地；
- 文件模式支持拖拽上传，大文件 MD5 计算速度取决于浏览器性能。
