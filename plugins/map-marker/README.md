# 地图标点（map-marker）

纯前端地图标点插件，基于高德地图 JS API 实现坐标标注与移动轨迹可视化。

## 功能

- **经纬度标点**：输入经/纬度或点击地图添加标记，支持名称与颜色区分；
- **批量导入**：每行一条 `名称,经度,纬度`，或仅 `经度,纬度`（分隔符兼容空格/中文逗号），一键批量标点；
- **二维码识别**：上传含轨迹数据的二维码图片，jsQR 自动解析识别结果，确认后生成轨迹；
- **移动轨迹回放**：按时间轴播放轨迹，支持进度拖拽、倍速播放、暂停/重置；
- **持久化**：标记自动保存至浏览器 localStorage，刷新不丢失。

## 依赖

- 高德地图 JS API v2.0（需自备 Key：在高德开放平台创建 **Web 端（JS API）** 应用，在页面「配置」弹窗中填写；
  若该应用开启了安全密钥，需一并填写 securityJsCode，否则地图不显示）；
- jsQR（`frontend/jsqr.min.js`，用于二维码识别）。

## 轨迹数据格式

二维码内容须为 JSON，支持：`[{"时间": "经度,纬度"}]` 或 `{时间: [经度,纬度]}`。

## 附赠工具

- `frontend/generate_qr_stream.py`：将轨迹 JSON 编码为 QR-transfer 兼容的动态二维码视频；
- `frontend/simulate_yunfu_5min.py`：生成云浮市一天 24h 每 5 分钟模拟 GPS 轨迹数据。

## 注意事项

- 首次使用前需在高德开放平台创建 Web 端 JS API 应用，获取 Key 并填写；
- 附赠的 demo 文件用于**验证**：`yunfu*.json` 经 `frontend/generate_qr_stream.py` 生成 `yunfu*.mp4`，
  再由 qr-video-decode 插件扫码得到轨迹；`yunfu*.txt` 为数据说明（字段格式注释）。
  插件本身不提供 json / mp4 / txt 导入入口，唯一文件入口是二维码图片识别。
